# Vijayalakshmi Devan – Portfolio

Responsive portfolio website (HTML, CSS, JavaScript – no build step).

## Add project screenshots
Save images in the `images/` folder using these names (JPG, ~1200x750px):
astroved.jpg, instant-pooja.jpg, priest-services-astroved.jpg, astroved-speaks.jpg,
priestservices.jpg, tripura-foundation.jpg, vopec-pharma.jpg, pillai-center.jpg

If an image is missing, a coloured card is shown instead.

## Deploy with GitHub Pages
1. Create a repo named `<your-username>.github.io` (or any name).
2. Upload `index.html`, `README.md` and the `images` folder.
3. Settings -> Pages -> Source: "Deploy from a branch" -> `main` / `(root)` -> Save.
4. Site goes live at https://<your-username>.github.io/
